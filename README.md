# TechPulse - Next-Gen Technology & Lifestyle Blog 🚀

TechPulse is an ultra-modern, high-performance technology magazine and digital lifestyle web publication built with HTML5, CSS3, Vanilla ES6+ JavaScript, and Bootstrap 5.

## 🌟 Key Features

- 🌓 **Dark / Light Mode**: Seamless theme switching with persistent local storage state.
- ⚡ **Bento Grid Hero Layout**: Dynamic editorial lead stories with responsive bento-grid presentation.
- 🔍 **Live Search & Category Filtering**: Instant real-time article filtering by tags (AI & ML, Gadgets, Web Dev, Cybersecurity, Digital Lifestyle).
- 🔖 **Interactive Reading List / Bookmarks**: Save articles for offline reading with dynamic badge counter and toast feedback.
- 📊 **Silicon Benchmark Labs**: Standardized hardware performance and battery comparison tables.
- 📱 **Fully Responsive & Accessible**: Mobile drawer navigation, smooth reading progress bar, and SEO-optimized semantic HTML.
- ✉️ **Editorial Desk & Pitch System**: Interactive tip submission and media kit inquiry forms.
